Dashboard interaction specification

- Species canonical labels: Rainbow trout; Unspecified species is excluded from dashboard species selectors.
- Country map click applies country + selected species filters to the database and scrolls to it.
- Heatmap: full topic labels visible; clicking a cell applies species + topic filter and scrolls to database; clicking a species row applies species filter.
- Hierarchy level controls use actual ontology labels, not generic Level N.
- Add top-level topic filter alongside species.
- Topic hierarchy is an expandable tree; clicking any node filters the database to that node and descendants and scrolls to the database.
- Heatmap columns should be grouped by topic hierarchy to make clustering visible.
